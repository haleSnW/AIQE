# 公开质量看板展示模板

目标读者：想在 3 分钟内判断 AIQE 是否能区分模型质量变化、运行环境故障与数据缺口的开源访客。

## 运行

```bash
PYTHONPATH=src python3 examples/showcase_dashboard.py --out /private/tmp/aiqe-showcase
```

打开 `/private/tmp/aiqe-showcase/index.html`。数据全部来自 `AIQE.synthetic`，为公开合成结果，按六个不同日期排列。默认趋势显示评分均值；可切换通过率、执行成功率、时延、token 等已定义指标。基线与候选选同一分组的运行。数据内联 HTML，复制或上传前先确认来源等级。

## 展示时的五句话

1. 相同数据集和评分器版本下，显示模型 A 到模型 B 的分数变化。
2. 用例通过率与执行成功率并排：一次是模型表现，一次是执行链路。
3. 通过、判定失败、执行错误、未判定分别计数；缺失指标显示原因，不填零。
4. 趋势只连接同精度、同指标版本的有效点，缺失处断线。
5. 图中结果是合成示范；真实设备测量见单独摘要，真实数据导入仍需独立门禁。
